# Paso 8. Tu prompt de 4 pasos

**En la práctica del bucle 5 · tu proyecto.** Guarda el prompt que usaste y las dos cifras que comprobaste a mano.

Analizar con IA en 4 pasos: pregunta, datos, prompt y verificación. La IA calcula; tú respondes de que la cifra es cierta. Pide siempre que calcule con código y que enseñe la fórmula y los supuestos.

*Ejemplo 8.1. El prompt de Café Fandango*

| Paso | Qué hicimos |
| ------ | ------ |
| Pregunta | ¿Qué red tiene mejor ROI por primera compra? Decidir cómo repartir 1.500 € |
| Datos | `clientes.csv`, `costes.csv` y `diccionario.md`, sin datos personales |
| Prompt | Rol de analista, la pregunta, «calcula con código», tabla por red con fórmula y supuestos |
| Verificación | Clientes de TikTok (1.007) y coste de Instagram (12.943 €) con una tabla dinámica |
| Qué falló la IA | Llamó ROI al ROAS: no restaba el coste ni aplicaba el margen |
